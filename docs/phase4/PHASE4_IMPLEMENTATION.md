# Phase 4 文書取込・解析・差分レビュー

更新日: 2026-10-05

## 目的

PDF、画像、Word、Excel、テキスト等の受付文書をローカル環境で解析し、書類種別・対象物候補・主要項目・既存台帳との差分候補を提示する。
解析結果は本番データへ自動反映せず、人間レビューと明示的な反映操作を必須とする。

## 対応入力

- PDF: 埋込文字を優先し、文字がない場合はOCR
- JPEG/JPG/PNG/WebP/TIFF: OCR
- DOCX: 段落・表セル抽出
- XLSX/XLSM: セル値抽出
- TXT/CSV/TSV: テキスト抽出

原本は変更せず共有ストレージへ保存し、SHA-256を保持する。

## 安全制約

- 解析対象は管理ストレージ配下のファイルのみ。
- 同期解析は100MBまで。
- PDF OCRは最大20ページまで。上限超過は後続の非同期処理対象とする。
- 抽出文字数は最大250,000文字。
- Excelセル走査は最大12,000セル。
- HEIC、旧DOC、旧XLSはPhase 4初期対象外。未対応形式は422として扱い、勝手に変換しない。

## 書類分類

初期の決定的分類ルール:
- 消防用設備等点検結果報告
- 防火管理者選任・解任関係
- 消防計画

分類には根拠キーワードとConfidenceを保持する。
将来のLocal LLM分類はこの決定的ルールの上位補助として追加し、根拠とモデルVersionを保存する。

## 対象物候補

抽出した名称・所在地と本文を既存防火対象物DBと照合し、候補上位5件をScore・理由付きで提示する。
自動確定は行わず、職員が対象物を選択する。

## 差分候補

Phase 4初期は以下のみ差分候補にする。
- 名称
- 所在地
- 電話番号

差分は `current` と `proposed` を保持する。
レビュー時点の `expected_facility_version` を保存し、対象物が後から変更された場合は409で適用を拒否する。

## Human Gate

フロー:

1. 原本アップロード
2. 文書解析
3. 書類種別候補・対象物候補・抽出値表示
4. 職員が対象物・書類種別を確認
5. 差分候補生成
6. 正式届出番号・提出日等を職員入力
7. 受付確定
8. 台帳差分は項目単位で明示的に選択
9. 選択された項目のみ対象物DBへ反映

受付確定前にHuman Reviewが無い場合は409で拒否する。
台帳差分は空の承認リストでは適用できない。

## 正式届出番号

正式番号は既存番号取得システムを正本とし、本システムでは数字のみ保存する。
接頭辞・「号」等を自動付加しない。

## 監査

以下を監査ログへ保存する。
- 原本登録
- 文書解析
- 人間レビュー
- 受付確定
- 台帳差分反映
- 使用した対象物ID、書類種別、差分Path

全文や個人情報を不要に監査ログへ複製しない。
