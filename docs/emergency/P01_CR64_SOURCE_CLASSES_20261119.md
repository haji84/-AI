# P01: CR-001〜CR-064 条件分岐の根拠種別・例外ゲート

更新日: 2026-11-19。参照: 全国版48頁（過去対象期間）、地域版28頁（参考資料）、利用者の明示運用、旧監査CSV。**P01・P02は未合格。正式合格とは扱わない**。個人・実原本データは保存しない。

## 判断原則

- SOURCE_CANDIDATE: 提供資料の該当規定と対応するが、本番有効化不可。SOURCE_SCOPED: 例外・適用範囲の限定が必須。
- USER_OPERATION: 本人が提示した運用。原文にあると偽らない。SOURCE_AND_USER: 既存原文と現行の本人運用が両方根拠で、適用範囲を区別。
- DESIGN_GUARD: AIが誤判定を防ぐための方針で、入力要領の明文規則ではない。
- AI_SUSPICION_EXAMPLE: 地域資料の「よくあるミス」に基づく疑義候補。年齢や医学判断を無視したハードエラーにはしない。
- USER_OPERATION_HOLD_FIELD / USER_OPERATION_NEEDS_CONFIRMATION: 正確な入力欄と正式運用が確認できるまで、本人への要確認提示に留める。

## CR64の分類集計

- USER_OPERATION_HOLD_FIELD: 1件
- SOURCE_CANDIDATE: 30件
- SOURCE_SCOPED: 22件
- USER_OPERATION_NEEDS_CONFIRMATION: 1件
- DESIGN_GUARD: 5件
- SOURCE_AND_USER: 1件
- AI_SUSPICION_EXAMPLE: 4件

分類は候補の根拠種別を管理するもので、本番承認数ではない。全64件の原文逐語二重校閲や現行欄コード対応を済ませた意味ではない。

### P02への受渡し禁止・優先順

1. CR-001は新様式内の2欄だけ。CR-002の別台帳間の事故種別差を消さない。2欄の位置と正式コード不明ならHOLD_FIELD。
2. CR-006〜017の不搬送/転院/途上引揚げ例外を先に解決。印字なしと入力なしの同一視禁止。
3. CR-019〜040は年齢区分（傷病者属性）と緊急度専用の年齢帯・総合判断を別スコープ。医学的正常値と赤閾値を混ぜない。
4. CR-041〜049は軽症フローと発生場所の独立条件。CR-045は通常帳票の住宅階層とウツタイン必須条件の同一視を禁止。
5. CR-050〜064は通報/病院照会実電話回数と記録回数の例外、観察に関するAI疑義、非印字欄をそれぞれ異なる判定に分離。

保留・確認待ちを除いた候補だけをP02で正規化することは可能。**P01逐語ゲートとP03現行版の採用が済む前に「正式Rule」の状態には移さない。**
