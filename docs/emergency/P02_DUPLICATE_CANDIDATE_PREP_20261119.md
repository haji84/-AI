## 2. P02で必要な設計

- 正規ルールは `Rule ID / 資料版 / 適用開始・終了 / 対象本部 / 対象画面・原本欄 / 入力条件 / 除外・優先 / 期待入力 / 不一致の扱い / 未検査の条件 / 出典 / Human承認 / 適用状態` を持たせる。
- 該当事項が印刷PDFにない場合は、入力画面の確認を許可された連携経路で取得できるまで `NOT_TESTED`。単なる空白を違反・正常のいずれとも扱わない。
- P03の正式現行運用資料がない限り、旧全国版・地域参考版による個別ルールは `PROVISIONAL_NOT_APPROVED`。本人提示運用の新様式事故種別2欄は、P04の正式な2欄コード特定まで強制実行しない。
- `SOURCE_CANDIDATE`、`USER_OPERATION`、`DESIGN_GUARD`、`AI_SUSPICION_EXAMPLE`、`HUMAN_JUDGMENT` を同一の「確定エラー」に押し込めない。
- 最終P02では重複候補すべてに元ER/CR/EXのトレースと、未統合の理由、独立テスト仕様を持たせる。
