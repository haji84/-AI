# P01: ER-001〜ER-202 原文意味照合・候補採否の個別インデックス

更新日: 2026-11-19。開発正本: PR #142。**P01全体は未合格**。患者データや原本画像はGitHubに収録しない。

## この表が証明すること／しないこと

- 旧202候補の各IDを原本該当ページ（全国版N・地域参考版L）の画像と照合し、**各候補の意味・例外・誤拡張に関する監査メモ**を列記した。別頁との併読や改訂確認を要するものはSOURCE_SCOPEDまたはHOLDとした。
- **202件の正式現行ルールが合格した証明ではない。** 既存の「根拠欄・短句」は原文逐語引用ではなく要約が混ざるため、全候補の完全な原文文字列転記・二者独立の逐語証明まで達成したとは宣言しない。特に必要な全文引用・改訂適用・例外の証拠は後続ゲートへ残す。
- SOURCE_CANDIDATEは「提供された原文ページに同名の対象項目・基本条件がある」段階、SOURCE_SCOPEDは「原文内の条件やQ&A例外で適用範囲を限定する」段階。どちらも本番利用許可ではない。HOLDは根拠不足または現行の項目名・コード未確定で**絶対に強制適用しない**。
- SOURCE_PLUS_DESIGN_GUARDは原文規定とAI安全設計を分離。HUMAN_JUDGMENTは患者状態や正式な臨床判断をAIで確定しない。
- 提供全国版は2021〜2022対象、地域版は2026年1月の参考資料。現行の正式版承認（P03）と新様式の欄ID対応（P04）は別の停止条件。
