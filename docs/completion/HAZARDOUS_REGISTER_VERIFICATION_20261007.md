# 危険物台帳: 実装範囲と検証

仕様16の原本に基づく台帳・履歴を実装する限定範囲です。法令適合を判定する危険物Rule評価は未実装であり、仕様16全体の完了とは扱いません。初期設計の基準は `c1b684c5c38fc52fe908d2116a21a16ef48dcb34`、今回の再統合基準mainは `1d76f081ab7cb277a2eb6338b1ef5e54d6ed4bf8` です。PR68のナビゲーション制御、PR67の受付ライフサイクル、PR72の画面状態待ちを保持します。

## 使用手順

1. Human管理者が危険物台帳の参照・作成・更新・証拠確認権限と、必要な対象物・原本の権限を職員に割り当てます。既存の一般ロールへの自動追加はありません。
2. 「危険物台帳」から既存の対象物を選び、施設・設備の名称、職員が確認した区分、所在地の補足、物質と数量・容量・単位を登録します。数量は小数文字列として正確に保持し、自動換算や丸めはしません。
3. 許可・届出・変更の記録を作成し、原本をアップロードするか、権限内の既存原本を選びます。法令の版、同じ対象物の査察・違反案件、記録日、職員が設定した期限も関連付けられます。
4. 原本・根拠・版・ハッシュを確認し、理由と明示的な確認操作により「Human証拠確認済」にします。これは証拠を照合した記録であり、許可の発行や法令適合の自動判断ではありません。
5. 事実や原本が変更された場合、以前の確認は過去の確認として表示します。草案を訂正保存して根拠を再確認するか、確認済記録から改訂草案を作成します。過去の記録は消さず、改訂・取消・廃止の履歴を保持します。

「記録の期限」、関連する原本・査察・違反案件、履歴へ同じ画面から移動できます。横断検索は施設・設備の台帳情報と元記録への参照を返し、証拠本文を複製しません。

## 保護と検証範囲

- 元のFacility/Document/Inspection/Violationを再利用。原本は実際のバイト列とSHA-256を照合し、元資料の所有権限も確認します。
- 草案保存時と確認時の根拠を比較し、途中で変わった原本・対象物・関連違反の証拠を黙って確認しません。
- 非表示の証拠は記録・期限・履歴の一覧から除外します。一般監査には証拠本文や原本名を載せず、変更ハッシュを記録します。
- 現在のセッション・権限、楽観版、関連行ロック、同一対象物を確認します。確認済記録と履歴にはPostgreSQLの変更防止制約を追加します。
- 052のみ追加。未公開作業が予約する051、既存046の欠番、過去の移行ファイルは変更しません。
- 保存中の原本アップロードは送信完了までフォーム保存を止めます。書込み成功後の読込み失敗は再読込みとして回復し、同じ書込みを再送しません。
- ログアウト・権限変更・新しい画面操作後の古い応答を破棄します。

独立レビューで見つかった監査経由の証拠露出、原本所有権限の抜け、古い関連画面への移動、保存後の読込み失敗、アップロード中の保存競合を再現し、回帰テストを追加して修正しました。PR68統合後のローカル全体は798件成功・136件スキップ、台帳検索と画面状態の対象テストは26件成功・4件スキップでした。独立したバックエンド・画面・統合レビューを実施し、50移行SQLの解析と全JavaScriptの構文検査を実施済みです。実PostgreSQLの競合・制約・アップグレード、実Chromiumの操作は正確なPR headのCI結果を確認します。ローカルではChromiumを起動していません。

## 2026-10-07 再統合の検証

- 危険物専用原本は、台帳への紐付け前でも `hazardous.read` がない場合に共通の原本・検索・受付経路から取得できません。一般原本の既存の所有権限は保持します。
- 期限一覧などの新しい読込みでは以前の操作ボタンを即座に読込表示へ置き換えます。読込み失敗は同じ条件で再試行でき、保存失敗時の入力は保持します。
- 独立した再統合レビューで、PR67の競合検出・対象物必須・更新権限チェックを保持していることを確認しました。対象テスト98件成功・99件スキップ、50移行SQLの解析、全JavaScriptの構文検査が成功しました。スキップしたPostgreSQL・実Chromiumは、このPRの正確なheadに対するCIで確認します。先の全体件数はその時点の履歴であり、今回の全体結果ではありません。

## 残る範囲

危険物Rule評価と承認済みの法令条件、全体の受入れ、実際の自治体資料・方針・本番権限・運用環境の確認は別途必要です。法定数量・区分・法的結論を推測して登録しません。勤務・統計の未公開作業、分散PCワーカー、災害復旧構成の変更は含みません。

関連違反の一覧を開く途中で危険物画面を閉じた場合、内容を表示しない違反画面の枠が残ることがあります。閉じる操作は可能で、取り消した読込み結果や証拠は表示しません。この表示上の改善は未解決です。
