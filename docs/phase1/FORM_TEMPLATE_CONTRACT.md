# Official Form Template Contract

正式様式が存在する場合はその原本を優先する。

保持項目:
- template_code
- template name
- module
- source document_id / SHA-256
- version_label
- issuer
- effective_from / effective_to
- field_mapping
- print_settings
- modification_policy

`fill_only`の場合、AI/プログラムは所定欄への値差込のみ許可し、原本レイアウトを正式様式として勝手に再設計しない。

様式改正は新Version登録とし旧Versionを削除しない。案件基準日時に適用されるVersionを選択できること。
